# Project 01 – Sales & Profit Analysis Dashboard

## Project Overview

An interactive Tableau dashboard created to analyze sales, profit, regional performance, and monthly order quantity trends.

## Objective

The objective of this project is to analyze business performance across different regions and identify sales, profit, and order-quantity trends.

## Dashboard Analysis

* **Region vs Sales** – Compares sales contribution across regions.
* **Profit vs Sales** – Shows the relationship between sales and profit.
* **Region-wise Profits** – Compares profit performance across regions.
* **Month vs Order Quantity** – Analyzes monthly order quantity trends.
